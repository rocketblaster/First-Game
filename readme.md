# Simple Platformer

## What is this?

This is my First Game project for Jumpstart Haven. It is a game where you play as the character Miku and collect notes in a classroom. This was made in Godot.

The features is a custom sprite for charcter, notes and at the end there is a yellow finish line that triggers the win screen. You can retry to try again!

## Demo
[Check it out on itch.io!](https://rocketblaster.itch.io/simple-platformer)

## How to play

Press WASD, space or arrow keys to move left, jump or right to jump over the block
